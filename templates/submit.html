Submit a tool

For software, packages, databases, spectral libraries, web services, repositories, APIs, or executable workflows.

Required information

  • Name and best link
  • Short neutral description
  • Main function and analytical platform
  • Interface and access model
  • Your relationship to the resource

STRATEGIES

Submit a strategy

For a published, transferable experimental or computational strategy that combines metabolomics steps or tools to solve a defined problem.

Required information

  • Strategy or method name
  • Publication DOI or URL
  • The problem it solves
  • Main analytical platform and objective
  • Tools/resources used
  • Your relationship to the work

What happens next

One review pathway for both content types

  1. You complete a short form.No YAML, Git, or pull-request knowledge required.
  2. Automation creates a structured draft.Known tool names are cross-linked automatically in strategy submissions.
  3. Validation checks the record.Schema, categories, and cross-links are checked before merge.
  4. An editor reviews and merges it.The public site rebuilds automatically from the approved record.

Submitting through GitHub currently requires a free GitHub account.
