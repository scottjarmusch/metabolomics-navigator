From suggestion to shared resource

  1. Submit
  2. Structured draft
  3. Validation
  4. Editorial review
  5. Publish

A GitHub account is needed. New-entry forms create structured drafts; update forms open correction issues. Editors check scientific scope, evidence, metadata and neutral wording before publication.

Authors, developers and users are welcome. Please disclose any connection to the resource. Developer or author verification is recorded separately from editorial review.
