# Population batch 01 — GNPS, SIRIUS, and MZmine ecosystems

This content-only batch enriches five existing tool entries and adds eleven published protocol/workflow entries. It does not change schemas, controlled vocabulary, forms, or GitHub Actions.

## Enriched tools

- GNPS / GNPS2
- MASST
- ReDU
- SIRIUS
- MZmine

## Added protocols

### GNPS ecosystem
- Classical molecular networking in GNPS
- Feature-Based Molecular Networking (FBMN) in GNPS
- Ion Identity Molecular Networking (IIMN) in GNPS
- Repository-scale MS/MS searching with MASST

### SIRIUS ecosystem
- Molecular-formula annotation with SIRIUS and ZODIAC
- Structure database search with CSI:FingerID and COSMIC
- Compound-class prediction with CANOPUS
- De novo structure generation with MSNovelist in SIRIUS

### MZmine workflows
- Untargeted LC-(IMS)-MS processing and annotation with MZmine
- GC-EI-MS processing and annotation with MZmine
- MS-imaging processing and annotation with MZmine
