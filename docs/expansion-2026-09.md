# September 2026 catalogue expansion

Editorial reading completed 7 September 2026. This batch adds six resources to the original 25 tools; the 13 strategy records remain unchanged.

| Resource | Role | Primary documentation | Publication |
| --- | --- | --- | --- |
| MetFrag | Fragment-based candidate ranking | [Project](https://ipb-halle.github.io/MetFrag/), [command-line guide](https://ipb-halle.github.io/MetFrag/projects/metfragcl/) | [Ruttkies et al., 2016](https://doi.org/10.1186/s13321-016-0115-9) |
| MS-FINDER | Formula and structure interpretation | [Project](https://systemsomicslab.github.io/compms/msfinder/main.html), [console guide](https://systemsomicslab.github.io/compms/msfinder/consoleapp.html) | [Tsugawa et al., 2016](https://doi.org/10.1021/acs.analchem.6b00770) |
| MassBank | Reference mass spectra | [Data repository](https://github.com/MassBank/MassBank-data), [current software and citation](https://github.com/MassBank/MassBank3) | [Neumann et al., online 2025](https://doi.org/10.1093/nar/gkaf1193) |
| MoNA | Aggregated spectral libraries | [Query guide](https://mona.fiehnlab.ucdavis.edu/documentation/query), [downloads](https://massbank.us/downloads), [developer resource listing](https://fiehnlab.ucdavis.edu/projects/softwaredev) | No dedicated resource paper confirmed in this pass; cite the reference data used. |
| MetaboLights | Study deposition and metadata | [Submission guides](https://ebi-metabolights.github.io/guides/), [assay metadata](https://ebi-metabolights.github.io/guides/Assay/) | [Yurekten et al., 2024](https://doi.org/10.1093/nar/gkad1045) |
| Metabolomics Workbench | Study repository and programmatic retrieval | [Repository](https://www.metabolomicsworkbench.org/), [REST documentation](https://www.metabolomicsworkbench.org/tools/mw_rest.php), [mwTab specification](https://www.metabolomicsworkbench.org/data/mwTab_specification.pdf) | [Sud et al., 2016](https://doi.org/10.1093/nar/gkv1042) |

Selection fills gaps in candidate annotation, reference libraries and whole-study sharing. It is not a popularity ranking or an exhaustive literature search. The new entries describe inputs, outputs, practical uses, requirements, interpretation limits, access and related resources. Maintenance and operational verification dates are intentionally absent where not assessed.

Recent reviews are available, including [Recent advances in mass spectrometry-based computational metabolomics (2023)](https://pubmed.ncbi.nlm.nih.gov/36966702/) and [Computational methods for processing and interpreting mass spectrometry-based metabolomics (2024)](https://portlandpress.com/essaysbiochem/article/68/1/5/233771/Computational-methods-for-processing-and). These provide context for discovery; the entries rely on resource documentation and primary publications. Navigator complements reviews with editable, structured practical guidance.

Readiness checks establish field coverage, not scientific certification. A beta reviewer should assess whether the stated scope is accurate, whether a newcomer can select a resource, and whether the linked guidance is sufficient to begin. Report corrections through each entry's update form.
