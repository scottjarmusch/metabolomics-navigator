# Inclusion, verification, and lifecycle definitions

This document is the operational reference for editors.

## Tool inclusion test

Include a resource when all of the following are true:

1. It is identifiable by a stable name or canonical project identity.
2. It has a public or documentable access point, publication, repository, or vendor page.
3. It performs, supports, stores, searches, or interprets a task relevant to metabolomics.
4. Its description can be written neutrally and categorized using the Atlas vocabulary.

Do not create separate entries solely for routine software versions. Use aliases and tool relationships for renamed, nested, or successor resources.

## Protocol inclusion test

Include a protocol when all of the following are true:

1. It is tied to a publication or stable published protocol.
2. The method or strategy itself is transferable beyond the original application study.
3. It addresses a defined analytical or biological metabolomics problem.
4. Its major workflow stages and required tools/resources can be described.

Exclude ordinary application studies unless they introduce or clearly codify a reusable methodological strategy.

## Verification language

“Developer verified” and “Author verified” indicate confirmation of entry content by a relevant creator. “Editorially reviewed” indicates an Atlas editor checked the record. None of these labels indicates endorsement, benchmarking, or validation of performance.

## Retention policy

Do not remove obsolete tools merely because they are old. Archive them when they remain necessary for reproducibility or historical interpretation. Link successors and predecessors when possible.
