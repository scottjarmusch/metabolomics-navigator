# GitHub setup

## 1. Create labels

The automation expects these labels:

- `tool-submission`
- `tool-update`
- `needs-triage`
- `automated-draft`

With GitHub CLI installed:

```bash
gh label create tool-submission --color 0E8A16 --description "New catalogue tool submission"
gh label create tool-update --color 1D76DB --description "Correction or update to an existing entry"
gh label create needs-triage --color FBCA04 --description "Needs editorial review"
gh label create automated-draft --color BFD4F2 --description "Draft generated by repository automation"
```

## 2. Enable GitHub Pages

Open **Settings → Pages** and choose **GitHub Actions** as the publishing source.

## 3. Workflow permissions

Open **Settings → Actions → General** and ensure workflows can read and write repository contents and create pull requests. Organization policies may override this setting.

## 4. Project URLs

This package is already configured for `scottjarmusch/metabolomics-tool-atlas`, including the expected GitHub Pages URL. No local configuration command is required.

## 5. Test the submission route

Open **Issues → New issue → Submit a metabolomics tool**, submit a test record, and verify that the `Create draft entry from submission` workflow opens a pull request.
