# Catalogue expansion: 7 September 2026

This editorial batch adds 50 distinct resources to the previous 31, for a total of 81. It broadens MS, NMR, lipidomics, natural-product, statistical and reference-data coverage. Selection was purposive, not a systematic or exhaustive review.

Each entry records official documentation, intended use, input/output context, access notes, requirements and interpretation limits. Bibliographic records were checked where included. Package records and documentation are labelled separately from research papers. Missing publication confirmation is explicit. No software execution, performance benchmarking or developer endorsement is implied.

The homepage presents six task categories; detailed category pages and the searchable catalogue retain the longer guidance. Community submissions and corrections continue through the existing reviewed contribution process.
