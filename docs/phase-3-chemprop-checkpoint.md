# Chemical Proportionality checkpoint

Added canonical `chemprop` as a Tool, not a Strategy or a duplicate version page. The current app exposes ChemProp1 and ChemProp2; the entry distinguishes their two-point and sequential scoring modes and the unrelated molecular-property prediction package named Chemprop.

Sources reviewed on 10 September 2026: the official Functional-Metabolomics-Lab/ChemProp-Web-App repository and Home.py interface documentation, its BSD-3-Clause license, GNPS2 MetaboApps listing, and Crossref metadata for DOI 10.1021/acs.analchem.1c01520.

Only the original Chemical Proportionality publication is included in core publications. The app homepage's generic FBMN-Stats citation was not copied. Attribution and publication status of the ChemProp2 manuscript need a separate follow-up; this limitation is explicit in the entry. No jobs or independent benchmarks were run.

Relationships connect MetaboApps, GNPS2 FBMN input and the USI-dependent ModiFinder integration. Manual uploads do not provide the latter integration. Core scientific caveat: abundance patterns prioritize hypotheses and do not establish conversion or causality.
