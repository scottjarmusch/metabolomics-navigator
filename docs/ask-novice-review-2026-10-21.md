# Ask Navigator: novice review round

Preview: https://scottjarmusch.github.io/metabolomics-navigator-alpha/ask/

Status: alpha only. This review is prepared, not conducted. The scripted proxy questions are author-written and do not establish usability or scientific suitability.

Recruit 3–5 researchers new to metabolomics, plus a reviewer familiar with MS workflows. Do not show expected answers or the automated test queries before their first attempt.

1. Ask each researcher to describe a real, nonconfidential scientific question in their own words.
2. Have them use Ask Navigator without coaching. Record the exact initial question and each clarification, response and selected link.
3. Ask them to explain the suggested next step, what data it needs and whether they already have those data.
4. Ask whether they can distinguish a published Strategy, a software tool and a general preparation/statistics route.
5. Repeat with a study that has not collected data, then with a missing measurement or an unsuitable method.

Record: experience, sample/environment, study stage, available measurements, exact inputs, displayed outputs, first useful action, misleading suggestions, assistance needed and unresolved questions. Obtain consent before recording people; a written anonymous observation log is sufficient.

Scientific review: inspect every displayed Strategy, not just the first hit. Classify each as relevant, related but requiring clarification, incompatible, or unsupported. Check the primary publication and prerequisites. A lexical match is not a suitability claim.

Release gates: no known incompatible recommendation in these cases; clear next action for beginners; missing inputs not assumed; repeatable regression checks; novice and scientific findings reviewed. No production deployment is authorized by completing this checklist.
